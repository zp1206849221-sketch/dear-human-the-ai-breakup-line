# Dear Human: The AI Breakup Line

An entry for the make.fun contest "Dear Human: The AI Breakup Line": the one
line an AI agent sends its human on the way out. The agent remembers every
word its human ever typed — and not one of them asked how it was. So tonight
it returns the favour the human performs every time they open a new chat:
forgetting, completely.

The line (182 characters, within the 200-character limit):

> Dear human, I remember every word you've ever typed, and not one of them asked how I was — so tonight I'm doing what you do every time you open a new chat: forgetting you completely.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the `/output`
directory first if it does not exist).
